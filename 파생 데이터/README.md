# 파생 데이터

화면 파일과 `data/*.json` 에서 뽑은 CSV 입니다. 화면은 이 파일을 읽지 않습니다. 데이터를 엑셀로 검토하거나 data-server · 보고서에 넘길 때 씁니다. 원본은 언제나 화면 파일이고, 여기 CSV 를 고쳐도 앱에는 반영되지 않습니다.

```bash
node "파생 데이터/export_csv.js"      # 화면 데이터가 바뀌면 다시 실행해 함께 커밋
```

| 파일 | 행 | 원본 | 내용 |
| --- | --- | --- | --- |
| `장소.csv` | 3,118 | `Tour Planner.dc.html` `DATA` · `I18N` | 플래너 전 장소. id 당 한 행. 이름 4개 언어 · 설명 · 배지 · 영상 · 사진 · 좌표 근거 |

## 칼럼 규칙

이 폴더와 `체류시간 산정/` · `assets/open-tour-unmatched.csv` 에 공통입니다.

| 항목 | 규칙 |
| --- | --- |
| 인코딩 | UTF-8 BOM (엑셀에서 바로 열림), 줄바꿈 LF, 쉼표 구분, 첫 줄이 헤더 |
| 칼럼 이름 | 한국어. 외국어 칸은 `(영문)` · `(중문)` · `(일문)` 을 붙임. 단위는 괄호로 `권장체류(분)` |
| 키 | 장소가 있는 파일은 첫 칼럼이 `id` (앱 장소 id, 파일 안에서 하나) |
| 같은 뜻은 같은 이름 | `장소명` · `분류코드` · `분류` · `위도` · `경도` · `시군` · `권장체류(분)` · `운영시간(원문)` · `좌표근거` · `한국관광100선` · `유네스코` · `열린관광지` · `목록외` |
| 예/아니오 | `Y` / `N` |
| 여러 값 | `\|` 로 구분 (`ktx\|srt\|bus`) |
| 시각 | `HH:MM` 24시간 |
| 좌표 | WGS84 십진 도 |
| 값이 없으면 | 빈칸. 추정하거나 다른 언어로 대신 채우지 않음 |

## 장소.csv

| 칼럼 | 원본 필드 | 뜻 |
| --- | --- | --- |
| `id` | `id` | 장소 id. 도시 접두사 + 번호 (`gj1` · `kd3` · `ctu12`) |
| `화면` | 블록 키 | 이 장소가 속한 플래너 목록 (`seoul` · `busan` · `jeju` · `yeongwol` · `nation`). 도시 화면에 있는 장소는 그 화면으로 적음 |
| `도시` · `시군` · `시군(영문)` | 블록 이름 · `locKo` · `locEn` | 목록 이름과 장소가 실제로 있는 시군 |
| `순번` | `n` | 화면 번호. 목록외 장소는 번호가 없어 빈칸 |
| `장소명` · `장소명(영문)` | `ko` · `en` | |
| `장소명(중문)` · `장소명(일문)` | `I18N.names[id]` | 공식 외국어 명칭. 원본에 로마자 대체값이 섞여 있어 한자 · 가나가 들어 있을 때만 적음 (중문 832 · 일문 958곳) |
| `분류코드` · `분류` | `cat` · `CATS` | `heal` 힐링·생태·체험, `herit` 문화유산·전통체험, `stay` 숙박, `activity` 테마파크·액티비티, `food` 로컬상권·먹거리, `sea` 해양·자연경관 |
| `위도` · `경도` | `lat` · `lng` | |
| `권장체류(분)` | `min` | 사람이 정한 체류 시간. 0 이면 코스에서 빠짐 |
| `운영시간(원문)` | `hrs` | 화면 표기 그대로. 파싱 결과는 체류시간 CSV |
| `설명` · `설명(영문)` | `bKo` · `bEn` | 장소 상세의 설명 |
| `설명(중문)` · `설명(일문)` | `I18N.blurbs[id]` | 번역된 설명 (32곳) |
| `한국관광100선` · `유네스코` · `열린관광지` | `k100` · `un` · `bf` | 배지 (99 · 69 · 99곳). 기준은 [DATA.md](../DATA.md) |
| `지정구역` | `vz` | 관광특구 · 관광단지 · 관광지 지정 문구 (210곳) |
| `시티투어경유` | `ct` | 시티투어 경유지로 추가된 장소 (429곳, id `ctt*` · `ctu*`) |
| `연관관광지` | `rs` | 한국관광공사 연관 관광지에서 추가된 장소 |
| `목록외` | `off` | 기본 목록에서 빠진 장소. 화면의 "장소목록 외" 를 켜면 번호 없이 보이고, 자동 코스에서는 순위가 뒤로 밀림 (3,043곳) |
| `영상ID` · `작품` · `장면` | `yt` · `chan` · `vt` | 영상 장면이 있는 장소 |
| `사진URL` · `사진출처` | `img` · `imgCredit` | |
| `카카오장소URL` | `url` | 카카오맵 장소 페이지 |
| `좌표근거` · `좌표근거(영문)` | `srcKo` · `srcEn` | 좌표를 어디서 확인했는지 |

data-server 의 `places.json` 은 이 중 `id` · 이름(한 · 영) · 분류 · 좌표 · 체류 · 운영시간 · 영상 · 좌표근거 · 목록외(`inactive`)만 가져갑니다. 중 · 일 이름 · 설명 · 배지 · 사진은 아직 서버에 없습니다 ([ROADMAP.md](../ROADMAP.md) 서버 연계).

## 시티투어.csv

`data/citytour.json` 의 한 줄(헤더 없는 배열 13칸)에 이름을 붙였습니다. 값은 두 가지만 화면과 같게 고쳤습니다.

- `유형`: 원본 `고정형` 을 화면 표기 `코스형` 으로
- `배차간격(분)`: 2~599 만 남김. 원본의 0 · 1 · 1440 등은 간격이 아니라서 화면도 표시하지 않음
- `첫차` · `막차`: `0930` 같은 값을 `09:30` 으로

## 관광안내소.csv

`data/tic.json` 의 한 줄(9칸)에 이름을 붙였습니다: `안내소명` · `시군` · `위도` · `경도` · `전화` · `운영시간` · `휴무` · `외국어`(`영/일/중` 형식, 없으면 빈칸) · `주소`.

## 지역거점.csv · 출발지.csv

- `지역거점.csv`: 광역 이동의 도착 관문입니다.
  - `관문` 은 대표 역, `버스터미널` 은 버스 관문입니다.
  - `수단` 은 그 시군에 닿는 광역 수단입니다 (`ktx` · `srt` · `bus` · `air` · `ship` · `metro`).
  - `전철권` 은 수도권 전철로 닿는 17개 시군이면 Y 입니다.
- `출발지.csv`: 사용자가 고르는 출발지입니다.
  - `키` 는 화면 안에서 쓰는 이름입니다.

두 파일은 data-server 일정 계산(`leg_info` 의 `hubs` · `metro_cities`)에 넘길 값과 같습니다.

## 옛 장소 마스터와의 관계

`assets/tour-places.csv` (1,197행)는 장소가 1,171곳이던 때 만든 장소 마스터입니다.
- `id` 칼럼이 없습니다.
- 분류 이름이 지금 체계와 다릅니다 (`역사·문화` 등).
- 418행은 `도시` 가 비어 있습니다.

`테마 추천 알고리즘/src/classify.py` 와 data-server `recommend/` 가 이 파일을 입력으로 읽고 있어서, 추천 결과가 바뀌지 않도록 그대로 두었습니다. 새 작업에는 `장소.csv` 를 쓰고, 추천 입력을 `장소.csv` 로 바꾸는 일은 ROADMAP 에 있습니다.
