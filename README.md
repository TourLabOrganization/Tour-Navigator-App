# Tour Navigator App

영상 속 장소를 따라 걷는 여행 계획 앱입니다. 홈 화면 하나에서 다섯 개 테마 코스와 전국 통합 플래너로 들어가고, 장소를 고르면 날짜 · 교통 · 숙소까지 이어지는 동선을 자동으로 만들어 줍니다. 빌드나 서버 없이 HTML 파일을 여는 것만으로 실행됩니다.

## 메인 화면

<img src="assets/screenshots/home.png" alt="Tour Navigator 홈 화면 — 배너, 나의 테마 타일, 지금 인기 코스" width="320">

`Tour Navigator Home.dc.html` 을 브라우저에서 연 모습입니다. 390×844 프레임 기준.

위에서부터 네 덩어리로 읽힙니다.

**1. 헤더** — `TOUR NAVIGATOR` 워드마크, 검색, 알림(읽지 않은 개수 배지). 바로 아래 **내 테마 / 투어 플래너** 두 탭이 붙어 있고, 선택된 탭은 주황 `#b8431c` 로 반전됩니다.

**2. 배너** — 5장이 자동 회전합니다. 각 장은 테마 라벨(`RESCENE ROUTE`), 두 줄 헤드라인, 한 줄 설명, `1 / 5` 카운터, 하단 진행 막대로 구성됩니다. 탭하면 해당 테마 화면으로 들어갑니다.

**3. 나의 테마** — 2열 타일. RESCENE Route · 왕과 사는 남자 · 케데헌 서울 · 제주 K-Drama · 부산 영화 기행, 그리고 마지막 칸은 **테마 추가**(`+`) 자리입니다. 섹션 헤더 오른쪽의 `+` 도 같은 동작입니다.

**4. 지금 인기 코스** — 가로 스크롤 카드. 카드마다 분류 라벨(`UNESCO`, `COAST`), 코스 이름과 일정(`경주 2박 3일`), 촬영지 수와 주 이동수단(`촬영지 9곳 · KTX`)이 적힙니다.

**하단 탭** — HOME / ALERT / ME. 선택된 탭만 주황으로 채워집니다.

색·타이포·괘선은 [DESIGN.md](DESIGN.md) 의 Modernist 시스템을 그대로 따릅니다. 화면 전환은 페이지 이동 없이 같은 문서 안에서 일어납니다.

## 기능

- **지도** — Google Maps 위에 카테고리 필터와 도시 단위 클러스터. 장소 상세에는 좌표 근거 · 운영시간 · 요금 · 사진을 보여줍니다.
- **코스** — 출발일과 귀가일을 고르면 n박 m일로 나누고, 출발지 · 도착지와 하루 720분 예산에 맞춰 동선을 자동 생성합니다. 구간마다 이동 시간과 거리를 계산합니다. 산정 규칙은 [체류시간 산정/README.md](체류시간%20산정/README.md) 에 있습니다.
- **교통** — KTX · SRT · 고속버스 · 렌터카 · 국내선 항공 · 여객선(제주 · 울릉) · 카페리 · 도시철도(서울 · 부산 · 인천). 광역교통 → 현지 이동 2단계로 고르고, 출발지 → 환승 관문 → 도착 관문 체인과 시각표, 복수 경로 선택을 제공합니다. 지역별 광역 관문에 맞춰 예매 버튼이 바뀝니다.
- **내 플랜** — 코스를 이름 붙여 저장 · 불러오기 · 삭제하고, 일자별로 장소를 추가합니다.
- **숙박** — 동선 기준 25km 안의 숙소를 추천하고, 날짜가 채워진 예약 링크를 붙입니다.
- **다국어** — 한국어 · English · 中文 · 日本語 · Español. 플래너는 Français 도 지원합니다. 장소명과 운영시간은 한국관광공사 다국어 DB의 공식 표기를 씁니다.
- **해설** — 한국관광공사 오디오 가이드와 스토리텔링을 장소 상세에서 재생 · 열람합니다.
- **배지** — 유네스코 세계유산, 한국관광 100선(🏅), 열린관광지 무장애(♿)를 표시하고 필터로 걸러 볼 수 있습니다.
- **날씨 · 미세먼지 · 행사 · 연관 관광지** — 기상청 단기예보, 에어코리아 등급, 여행 기간에 열리는 축제·행사, 함께 많이 가는 관광지 (공공데이터포털 키 필요)
- **작품 정보** — 테마 화면의 영화·드라마 포스터와 줄거리 (TMDB 키 필요)
